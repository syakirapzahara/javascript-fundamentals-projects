# Daily Expenses Log

Proyek latihan JavaScript dasar: aplikasi pencatat pengeluaran harian.

## Live Demo

https://project-1b-daily-expenses-log.netlify.app/

## Fitur

- Mencatat pengeluaran dengan keterangan dan nominal
- Menghitung total pengeluaran dan sisa budget harian
- Menampilkan peringatan warna saat budget menipis atau habis
- Menyimpan riwayat pengeluaran
- Reset data harian

## Teknologi

- HTML
- CSS
- JavaScript (vanilla)

## Struktur File

- `index.html` — struktur halaman
- `index.css` — tampilan
- `index.js` — logika aplikasi

## Cara Menjalankan

Buka `index.html` di browser.

## Catatan

Proyek ini dibuat sebagai latihan setelah menyelesaikan proyek Passenger Counter.
