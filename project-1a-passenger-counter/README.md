# Passenger Counter

Proyek latihan JavaScript dasar: aplikasi penghitung penumpang.

## Live Demo

https://project-1a-passenger-counter.netlify.app

## Fitur

- Menambah jumlah penumpang (increment)
- Menyimpan riwayat entri
- Reset penghitung

## Teknologi

- HTML
- CSS
- JavaScript (vanilla)

## Cara Menjalankan

Buka `index.html` di browser.
