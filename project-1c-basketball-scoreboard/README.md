# Scoreboard

Aplikasi papan skor dua tim berbasis HTML, CSS, dan JavaScript.

## Live Demo

https://project-1c-basketball-scoreboard.netlify.app/

## Fitur

- Menambah skor untuk tim HOME dan GUEST
- Mencatat pelanggaran (fouls) masing-masing tim
- Peringatan warna pada jumlah fouls (Warning, Danger)
- Diskualifikasi tim saat mencapai batas fouls
- Pembatasan jumlah period pertandingan
- Penentuan pemenang otomatis
- Reset pertandingan

## Teknologi

- HTML
- CSS
- JavaScript (vanilla)

## Struktur File

- `index.html` — struktur halaman
- `index.css` — tampilan
- `index.js` — logika aplikasi

## Aturan Permainan

- Batas fouls: 5
- Maksimal period: 4
- Tim yang mencapai batas fouls tidak dapat menambah skor
- Pemenang ditentukan berdasarkan skor tertinggi saat pertandingan berakhir

## Cara Menjalankan

Buka `index.html` di browser.
